# Admin dashboard (admin2)

React 19 + Vite + Tailwind + Material UI + Recharts. See the [root README](../README.md) for setup and deployment.

```bash
cp .env.example .env   # set VITE_API_URL
npm install
npm run dev -- --port 5174
npm run build          # production build in dist/
```

Sign in with the account created by `npm run create-admin` in `server/`.
